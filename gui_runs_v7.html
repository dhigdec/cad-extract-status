How to read this. A run ends when the model says it is done or reaches 1500 steps. If FreeCAD or the harness crashes, that try is set aside (saved) and the run restarts from scratch; it is not scored. The score is 1.0 when every missing part is rebuilt in place within 1/16 in with every hole right and the given model untouched; otherwise 0.9 × the share of parts right. "What went wrong" lists the grader's diagnosis for the parts that failed (for example: part missing, shifted, turned, wrong shape, holes, clash with existing steel). Each run is recorded in full: desktop video, every screenshot, the model's reply and its reasoning-token count at every step (OpenAI's API returns Sol's reasoning as a token count only).
