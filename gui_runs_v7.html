FreeCAD GUI benchmark: five new rebuild tasks (v7)

Updated 13 Nov 2026, 22:09 UTC · this page refreshes itself every minute
Each run gives an AI model a real steel model with some pieces removed, plus the fabricator's drawings of those pieces. The model must rebuild the missing pieces in the FreeCAD desktop app using only the mouse and keyboard (no scripting), in exactly the right place, then save and export. 4 of 5 rebuild tasks published × 3 models × 3 attempts = 36 runs of GPT-6.1 Sol, Claude Opus 5.5 and Gemini 4 Argon (all high thinking), up to 1500 steps each, no time limit. Score 0 to 1: 1.0 = solved (every part within 1/16 in, every hole right, nothing else moved). These five tasks extend the 47-task benchmark, with the same setup as its runs: a task joins the benchmark when some model solves at most 1 of its 3 attempts. Each task's runs start as soon as it passes its final checks.

How to read this. A run ends when the model says it is done or reaches 1500 steps. If FreeCAD or the harness crashes, that try is set aside (saved) and the run restarts from scratch; it is not scored. The score is 1.0 when every missing part is rebuilt in place within 1/16 in with every hole right and the given model untouched; otherwise 0.9 × the share of parts right. "What went wrong" lists the grader's diagnosis for the parts that failed (for example: part missing, shifted, turned, wrong shape, holes, clash with existing steel). Each run is recorded in full: desktop video, every screenshot, the model's reply and its reasoning-token count at every step (OpenAI's API returns Sol's reasoning as a token count only).
