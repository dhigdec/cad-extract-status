Every 3D steel model in the perfect tier is turned into a headless, deterministic build123d script that rebuilds it part by part. Each model is verified per part against two references (the IFC source geometry and the delivered STEP), per assembly / piece mark, as a whole model, by running the packaged script exactly as a client would, and by rebuilding it twice for a byte-identical STEP. Numbers are read from the run's state every 5 minutes. No project or client names are shown.

Progress by model size

Size classes use delivered STEP file size. Allocating more memory to a job does not move its model into a larger size class. Bar = models processed; orange part = processed and perfect. A model is perfect only when every one of its parts is - so large models (median 12,000+ parts) need every remaining failure type fixed; "parts matching" shows how close they are. Rate = models finished in the last 30 minutes, per hour; the time left is at that rate.
