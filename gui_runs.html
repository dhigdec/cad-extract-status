Argon runs from 21 Oct 07:15 UTC: a reply cut off at the length limit (a runaway generation) is requested again for the same step, up to 3 times, instead of ending the attempt. A FreeCAD crash, harness error or time limit is not packaged: the run restarts from scratch (attempt 2, 3, …) and a note goes to gs://cad_gui_runs/runs_crashed/.
