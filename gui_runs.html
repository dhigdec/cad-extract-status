Phases: starting → agent running → grading (both scores) → packaging (Harbor job, recording, feature tree, trajectory) → uploaded (VM stops). Scores run from 0 to 1 (1 = every missing part and bolt rebuilt correctly). Strict grades the agent's own exported full.step (0 if it never exported); built grades what the agent built, exported by the grader from its latest saved FreeCAD document. A run is packaged when the agent declares the task done (at any step) or when it reaches the 500-step cap. A FreeCAD crash, harness error or time limit is not packaged: the run restarts from scratch (attempt 2, 3, …) and a note goes to gs://cad_gui_runs/runs_crashed/.
