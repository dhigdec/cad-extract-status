Phases: building / checks (the task is still being built and verified: oracle, no-op, grader probes, determinacy) → starting → agent running → grading (both scores) → packaging (Harbor job, desktop video, feature tree, trajectory with screenshots) → uploaded (the VM stops). A run ends when the agent declares the task done or when it reaches the 1500-step cap. A FreeCAD crash or harness error is not graded: that attempt is set aside and the run starts again from scratch (attempt 2, 3, …). Needs attention = no agent step for 15 minutes, a trial that ended without reporting, or a VM silent for 6 minutes. Scores run from 0 to 1: 1.0 = every missing part rebuilt in place within 1.6 mm with every hole right and the given model untouched; otherwise 0.9 × parts right × paired share. Strict grades the agent's own exported STEP, built grades the FreeCAD document it saved; the score is strict when the agent exported, else built. Gemini Argon runs (as in the earlier batch): a reply cut off at its length limit is asked again for the same step, a reply with a truncated draft before one complete action is read as that action, and an attempt with no step for 15 minutes is restarted.

Every graded run is cross-checked automatically for contradictions that would point at the grader rather than the model (a grader exception, a part saved in place but not found, an empty grading); a flagged run is held until it has been checked.
